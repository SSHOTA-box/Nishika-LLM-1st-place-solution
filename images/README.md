# Images

The public repository includes two generative-AI-created product-package images under `train/demo1/` and `train/demo2/`. They are synthetic examples for illustrating the expected directory layout and are not competition images.

All visible brands, companies, addresses, telephone numbers, dates, barcodes, nutritional claims, and product details in these images are fictional AI-generated content. They are not verified product information and must not be used for identification, contact, sale, consumption, or regulatory purposes.

Original competition images are not redistributed. Users with authorized copies should use this structure:

```text
images/
├── train/<ID>/*.{jpg,jpeg,png,bmp}
└── test/<ID>/*.{jpg,jpeg,png,bmp}
```

Only the two explicitly allowlisted demo images are tracked. Do not commit competition images or image-derived caches.
