# Contributing

Thank you for helping improve this project. Focused bug fixes, reproducibility improvements, tests, and documentation corrections are welcome.

Before opening a pull request:

1. Do not add competition data, product images, model weights, checkpoints, predictions, submissions, credentials, or private paths.
2. Keep algorithm or hyperparameter changes separate and explain their expected effect on results.
3. Run `python -m unittest discover -s tests -v`.
4. Update both `README.md` and `README_JA.md` when changing user-facing instructions. English is the source of truth.
5. Describe what was tested and identify any GPU, model, or dataset requirement that prevented full validation.

Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are accepted under Apache-2.0, consistent with Section 5 of the project license.

Use GitHub Issues for reproducible bugs and scoped documentation requests. Include environment details and a minimal log, but redact private paths and restricted data. Security-sensitive reports should be sent privately to the maintainer once a contact channel is published; do not disclose credentials in an issue.
